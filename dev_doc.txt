Era of Seafaring: Live Ocean · Architecture Specification v1.0 · TypeScript Strict Mode
架构设计总原则
本项目采用 Contract-First（契约优先）+ Slice-Based（状态切片）+ Pure-Function Core（纯函数核心）+ Feature Ownership（功能文件所有权） 的架构。
针对低参数 Coding LLM 与多个并行 Agent，重点解决四个问题：
Agent 不理解其他 Agent 的内部实现，仍能独立开发。  
Agent 之间不能同时修改同一个文件。  
每个模块可以使用 Mock 实现独立单元测试。  
程序化美术资源可以无业务代码修改地替换为正式美术资产。

不允许将 API 原始 JSON 直接写入 Zustand。

AssetKey 作为资产访问唯一标识，不允许组件拼接随机路径。

3.3 src/assets/AssetRegistry.ts
该文件是所有资产加载逻辑的唯一入口。
为满足严格 TypeScript，Manifest 的 JSON 导入采用 Vite 支持的 JSON 模块导入方式。下面给出核心完整实现。
// src/assets/AssetRegistry.ts

import type {
  AssetConfig,
  AssetKey,
  AssetManifest,
} from "../types";

import {
  generateVesselSvg,
  type VesselSvgOptions,
} from "./procedural/vesselSvg";

import {
  generateWeatherSvg,
} from "./procedural/weatherSvg";

import {
  generateCompassSvg,
} from "./procedural/compassSvg";

import {
  generateSeaWindowSvg,
} from "./procedural/seaWindowSvg";

type GeneratorName =
  | "vesselSvg"
  | "weatherSvg"
  | "compassSvg"
  | "seaWindowSvg";

export interface AssetRenderRequest {
  assetId: AssetKey;

  width?: number;
  height?: number;

  headingDeg?: number;

  vesselCategory?: VesselSvgOptions["category"];

  weatherLevel?: number;

  waveHeightM?: number;
}

export interface ResolvedAsset {
  assetId: AssetKey;

  mode: "procedural" | "image";

  url?: string;

  svg?: string;

  width: number;
  height: number;

  fallback: boolean;
}

const GENERATOR_MAP: Record<
  GeneratorName,
  (request: AssetRenderRequest) => string
> = {
  vesselSvg: (request) =>
    generateVesselSvg({
      category: request.vesselCategory ?? "Cargo",
      headingDeg: request.headingDeg ?? 0,
      width: request.width ?? 64,
      height: request.height ?? 64,
    }),

  weatherSvg: (request) =>
    generateWeatherSvg({
      level: request.weatherLevel ?? 1,
      width: request.width ?? 48,
      height: request.height ?? 48,
    }),

  compassSvg: (request) =>
    generateCompassSvg({
      headingDeg: request.headingDeg ?? 0,
      width: request.width ?? 64,
      height: request.height ?? 64,
    }),

  seaWindowSvg: (request) =>
    generateSeaWindowSvg({
      waveHeightM: request.waveHeightM ?? 1,
      width: request.width ?? 320,
      height: request.height ?? 160,
    }),
};

export class AssetRegistry {
  private manifest: AssetManifest | null = null;

  private readonly svgCache = new Map<string, string>();

  private readonly imageCache = new Map<string, string>();

  private readonly basePath = "/assets";

  public async initialize(): Promise<void> {
    const response = await fetch(
      `${this.basePath}/assetManifest.json`,
    );

    if (!response.ok) {
      throw new Error(
        `Asset manifest loading failed: ${response.status}`,
      );
    }

    const manifest = (await response.json()) as AssetManifest;

    this.validateManifest(manifest);

    this.manifest = manifest;
  }

  public getManifest(): AssetManifest {
    if (this.manifest === null) {
      throw new Error("AssetRegistry is not initialized");
    }

    return this.manifest;
  }

  public getConfig(assetId: AssetKey): AssetConfig {
    const manifest = this.getManifest();

    const config = manifest.assets[assetId];

    if (config === undefined) {
      throw new Error(`Unknown assetId: ${assetId}`);
    }

    return config;
  }

  public resolve(
    request: AssetRenderRequest,
  ): ResolvedAsset {
    const config = this.getConfig(request.assetId);

    const width = request.width ?? config.width;

    const height = request.height ?? config.height;

    if (config.mode === "image") {
      const imageUrl = this.resolveImageUrl(config);

      return {
        assetId: request.assetId,
        mode: "image",
        url: imageUrl,
        width,
        height,
        fallback: false,
      };
    }

    const generatorName =
      config.proceduralGenerator as GeneratorName | undefined;

    if (
      generatorName === undefined ||
      GENERATOR_MAP[generatorName] === undefined
    ) {
      throw new Error(
        `Missing generator for asset: ${request.assetId}`,
      );
    }

    const cacheKey = this.createCacheKey(request);

    let svg = this.svgCache.get(cacheKey);

    if (svg === undefined) {
      svg = GENERATOR_MAP[generatorName]({
        ...request,
        width,
        height,
      });

      if (config.cache) {
        this.svgCache.set(cacheKey, svg);
      }
    }

    return {
      assetId: request.assetId,
      mode: "procedural",
      svg,
      width,
      height,
      fallback: false,
    };
  }

  public resolveImageUrl(config: AssetConfig): string {
    if (config.overridePath !== undefined) {
      return config.overridePath;
    }

    return `${this.basePath}/override/${config.assetId}.${config.format ?? "webp"}`;
  }

  public setImageOverride(
    assetId: AssetKey,
    overridePath: string,
  ): void {
    if (this.manifest === null) {
      throw new Error("AssetRegistry is not initialized");
    }

    const config = this.manifest.assets[assetId];

    if (config === undefined) {
      throw new Error(`Unknown assetId: ${assetId}`);
    }

    config.overridePath = overridePath;
    config.mode = "image";

    this.svgCache.clear();
    this.imageCache.clear();
  }

  public setProceduralMode(assetId: AssetKey): void {
    if (this.manifest === null) {
      throw new Error("AssetRegistry is not initialized");
    }

    const config = this.manifest.assets[assetId];

    if (config === undefined) {
      throw new Error(`Unknown assetId: ${assetId}`);
    }

    config.mode = "procedural";

    this.svgCache.clear();
  }

  public clearCache(): void {
    this.svgCache.clear();
    this.imageCache.clear();
  }

  private createCacheKey(
    request: AssetRenderRequest,
  ): string {
    return [
      request.assetId,
      request.width ?? 0,
      request.height ?? 0,
      request.headingDeg ?? 0,
      request.vesselCategory ?? "",
      request.weatherLevel ?? 0,
      request.waveHeightM ?? 0,
    ].join(":");
  }

  private validateManifest(
    manifest: AssetManifest,
  ): void {
    if (manifest.version !== 1) {
      throw new Error(
        `Unsupported asset manifest version: ${manifest.version}`,
      );
    }

    const entries = Object.values(manifest.assets);

    for (const config of entries) {
      if (config.width <= 0 || config.height <= 0) {
        throw new Error(
          `Invalid dimensions: ${config.assetId}`,
        );
      }

      if (
        config.mode === "procedural" &&
        config.proceduralGenerator === undefined
      ) {
        throw new Error(
          `Procedural generator missing: ${config.assetId}`,
        );
      }
    }
  }
}

export function generateVesselSvg(
  options: VesselSvgOptions,
): string {
  const {
    category,
    headingDeg,
    width,
    height,
  } = options;

  const bodyColor = "#CBD5E1";
  const outlineColor = "#0F172A";

  let body = "";

  switch (category) {
    case "Cargo":
      body = `
        <path
          d="M32 5 L42 18 L45 45 L36 58
             L28 58 L19 45 L22 18 Z"
          fill="${bodyColor}"
          stroke="${outlineColor}"
          stroke-width="2"
        />
        <rect x="25" y="22" width="14" height="16"
          fill="#64748B"/>
      `;
      break;

    case "Tanker":
      body = `
        <path
          d="M32 5 L45 18 L48 45 L37 58
             L27 58 L16 45 L19 18 Z"
          fill="#64748B"
          stroke="${outlineColor}"
          stroke-width="2"
        />
        <rect x="24" y="18" width="16" height="28"
          rx="4" fill="#B45309"/>
      `;
      break;

    case "Sailboat":
      body = `
        <path
          d="M32 5 L42 18 L45 45 L36 58
             L28 58 L19 45 L22 18 Z"
          fill="#F8FAFC"
          stroke="${outlineColor}"
          stroke-width="2"
        />
        <path d="M31 12 L31 40 L18 40 Z"
          fill="#E2E8F0"/>
        <path d="M33 15 L44 40 L33 40 Z"
          fill="#94A3B8"/>
      `;
      break;

    case "Icebreaker":
      body = `
        <path
          d="M32 3 L47 20 L43 45 L36 58
             L28 58 L21 45 L17 20 Z"
          fill="#38BDF8"
          stroke="${outlineColor}"
          stroke-width="2"
        />
        <path d="M24 30 L40 30 L36 42 L28 42 Z"
          fill="#E0F2FE"/>
      `;
      break;
  }

  return `
    <svg
      xmlns="http://www.w3.org/2000/svg"
      width="${width}"
      height="${height}"
      viewBox="0 0 64 64"
    >
      <g transform="rotate(${headingDeg}, 32, 32)">
        ${body}
        <path
          d="M32 1 L27 11 L37 11 Z"
          fill="#F43F5E"
        />
      </g>
    </svg>
  `;
}

export interface SeaWindowSvgOptions {
  waveHeightM: number;
  width: number;
  height: number;
}

export function generateSeaWindowSvg(
  options: SeaWindowSvgOptions,
): string {
  const {
    waveHeightM,
    width,
    height,
  } = options;

  const amplitude = Math.min(
    50,
    Math.max(5, waveHeightM * 8),
  );

  const centerY = height * 0.55;

  const wave1 = `
    M0 ${centerY}
    Q${width * 0.25} ${centerY - amplitude}
     ${width * 0.5} ${centerY}
    T${width} ${centerY}
    L${width} ${height}
    L0 ${height}
    Z
  `;

  const wave2 = `
    M0 ${centerY + 10}
    Q${width * 0.25} ${centerY + amplitude}
     ${width * 0.5} ${centerY + 10}
    T${width} ${centerY + 10}
    L${width} ${height}
    L0 ${height}
    Z
  `;

  return `
    <svg
      xmlns="http://www.w3.org/2000/svg"
      width="${width}"
      height="${height}"
      viewBox="0 0 ${width} ${height}"
    >
      <defs>
        <linearGradient
          id="seaGradient"
          x1="0"
          y1="0"
          x2="0"
          y2="1"
        >
          <stop offset="0%" stop-color="#7DD3FC"/>
          <stop offset="100%" stop-color="#075985"/>
        </linearGradient>
      </defs>

      <rect
        width="${width}"
        height="${height}"
        fill="#0F172A"
      />

      <path
        d="${wave1}"
        fill="url(#seaGradient)"
      />

      <path
        d="${wave2}"
        fill="#0369A1"
        opacity="0.65"
      />

      <rect
        x="4"
        y="4"
        width="${width - 8}"
        height="${height - 8}"
        rx="8"
        fill="none"
        stroke="#94A3B8"
        stroke-width="4"
      />
    </svg>
  `;
}

// src/components/common/GameAsset.tsx

import {
  useEffect,
  useState,
} from "react";

import type {
  CSSProperties,
} from "react";

import type {
  AssetKey,
} from "../../types";

import {
  assetRegistry,
  type AssetRenderRequest,
  type ResolvedAsset,
} from "../../assets/AssetRegistry";

export interface GameAssetProps {
  assetId: AssetKey;

  width?: number;
  height?: number;

  headingDeg?: number;

  vesselCategory?:
    AssetRenderRequest["vesselCategory"];

  weatherLevel?: number;

  waveHeightM?: number;

  className?: string;

  style?: CSSProperties;

  alt?: string;
}

export function GameAsset(
  props: GameAssetProps,
) {
  const {
    assetId,
    width,
    height,
    headingDeg,
    vesselCategory,
    weatherLevel,
    waveHeightM,
    className,
    style,
    alt = "",
  } = props;

  const [resolved, setResolved] =
    useState<ResolvedAsset | null>(null);

  const [imageFailed, setImageFailed] =
    useState(false);

  useEffect(() => {
    const request: AssetRenderRequest = {
      assetId,
      width,
      height,
      headingDeg,
      vesselCategory,
      weatherLevel,
      waveHeightM,
    };

    const result = assetRegistry.resolve(request);

    setResolved(result);
    setImageFailed(false);
  }, [
    assetId,
    width,
    height,
    headingDeg,
    vesselCategory,
    weatherLevel,
    waveHeightM,
  ]);

  if (resolved === null) {
    return (
      <div
        className={className}
        style={{
          width,
          height,
          ...style,
        }}
        aria-label={alt}
      />
    );
  }

  if (
    resolved.mode === "image" &&
    resolved.url !== undefined &&
    !imageFailed
  ) {
    return (
      <img
        src={resolved.url}
        width={resolved.width}
        height={resolved.height}
        className={className}
        style={{
          objectFit: "contain",
          ...style,
        }}
        alt={alt}
        onError={() => {
          setImageFailed(true);
        }}
      />
    );
  }

  if (resolved.svg !== undefined) {
    return (
      <div
        className={className}
        style={{
          width: resolved.width,
          height: resolved.height,
          display: "inline-flex",
          alignItems: "center",
          justifyContent: "center",
          ...style,
        }}
        role="img"
        aria-label={alt}
        dangerouslySetInnerHTML={{
          __html: resolved.svg,
        }}
      />
    );
  }

  return null;
}
SVG 安全要求
上面的 dangerouslySetInnerHTML 只允许使用内部受控生成器输出。
不得将以下内容直接写入 SVG：
外部用户输入。  
AIS 船名。  
港口名称。  
未经过 Sanitizer 的 API 数据。  
外部 SVG 文件内容。  
正式美术 SVG 必须通过 Sanitizer，移除 <script>、foreignObject、事件属性和非允许的外部引用。

E2E-001：启动游戏

最终架构决策（ADR）
ADR-001：数据契约冻结
src/types/index.ts 由架构负责人维护，Agent 只读。
ADR-002：Core 必须纯函数
物理、油耗、补给、贸易、路线、离线结算均由纯函数实现。
ADR-003：Store 作为游戏动态状态唯一真相源
所有业务状态由 Zustand Slice 管理，UI 仅使用 Selector。
ADR-004：AssetRegistry 作为美术资源唯一入口
所有业务组件通过 GameAsset 获取资源，禁止直接引用原始路径。
ADR-005：Agent 文件所有权不可重叠
每个文件仅有一个 Owner，跨模块修改必须通过 ICR。
ADR-006：真实数据与模拟数据严格分离
AIS、天气、水深数据必须携带来源和质量标记。
ADR-007：离线挂机必须可重复结算
离线结算以存档时间戳为输入，受最大离线时间、燃油、补给、船体耐久等约束。
ADR-008：高频地图数据不进入持久化存档
真实 AIS 船舶位置、Deck.gl Layer 状态、临时天气缓存不写入永久存档。

推荐开发启动顺序
架构负责人冻结 src/types/index.ts、package.json、Vite 配置和测试框架。  
Agent 1、2、3、5、6 可以基于契约并行开发。  
Agent 4 使用 Mock AIS 和 Mock Store Selector 提前开发地图。  
各 Agent 先提交单元测试通过的模块。  
按 Step 3 顺序逐模块集成。  
最后执行浏览器 E2E、Capacitor iOS/Android 验收。  
最关键的工程约束：不要让 6 个 Agent 同时开发一个“完整游戏”。要让它们分别开发 6 个接口明确、文件所有权独立、可独立测试的系统。
这套规范可以作为 Codex、Claude Code、Antigravity 或其他多 Agent 编程工具的项目级开发基线。
